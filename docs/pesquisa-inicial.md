# Pesquisa inicial — Encontraê

Região confirmada: Pinhais e Curitiba, Paraná. Fontes consultadas em 27/10/2026.

- Autoatendimento de Pinhais: https://pinhais.atende.net/autoatendimento/
- Contatos de Pinhais: https://ws-pinhais.atende.net/cidadao/pagina/fale-conosco
- Telefones de Pinhais: https://ws-pinhais.atende.net/cidadao/pagina/lista-de-telefones
- Central 156 de Curitiba: https://156.curitiba.pr.gov.br/Servico/Veja-todos-servicos-para-atender-cidadao-da-central-156-prefeitura-curitiba
- Vagas de Curitiba: https://servicos.curitiba.pr.gov.br/vagas-de-emprego/159
- Trabalho no Paraná: https://www.trabalho.pr.gov.br/Trabalho

As fontes disponibilizam canais oficiais de atendimento. Nenhuma API pública para importar vagas ou abrir protocolos foi confirmada. O aplicativo encaminhará o usuário aos canais publicados.

A Central 156 informa o telefone (41) 3074-6456 para outras localidades e Região Metropolitana. Isso permite encaminhar moradores de Pinhais aos serviços de Curitiba.

Node.js, npm e Git estão disponíveis no PC. Flutter e Dart não foram encontrados no PATH. React Native, Expo e TypeScript permitem desenvolver uma base para Android e iOS: https://docs.expo.dev/tutorial/introduction/.
